# KA Text Detector

Локальный исследовательский анализ русских текстов. Продукт студии **«Код Александрова»**, разработка сервиса и интеграции — **Кирилл Александров**.

> Это оценка признаков, не доказательство авторства. Не использовать для санкций, экзаменационных или кадровых решений. Коммерческий выпуск весов пока не утверждён: лицензии дообученных моделей и происхождение корпуса требуют уточнения.

## Возможности

- Реальные локальные алгоритмы v1–v4: статистический классификатор с языковой моделью и три версии ruBERT. Без платных внешних ИИ API.
- FastAPI `/v1/status`, `/v1/analyze`, `/v1/extract`, изоляция и общий сервисный секрет.
- TXT UTF-8, DOCX и PDF с текстовым слоем; ограниченные процессы извлечения. OCR отсутствует.
- Карта контекстных сигналов, статистика, сравнение двух версий, fingerprint весов.
- Реестр с SHA-256, связь весов с отчётом испытаний, отдельная регистрация кандидатов.
- Оценка размеченного корпуса, доверительные интервалы, дедупликация и контроль split. Реальный CPU gradient/save smoke-test.

Интерфейсы, существующие аккаунты студии, серверные квоты и приватная история реализованы в отдельном проекте сайта. Кошелёк и «Импульсы» не реализованы.

## Запуск

Docker, Python 3.12, Linux x86-64. Проверенный запуск — через `compose.detector.yaml` локальной студии: [инструкция](docs/KA-RUNBOOK.md).

```sh
docker build -f Dockerfile.ka -t kodalexandrova-text-detector:local .
```

Нужны явно подготовленные артефакты и приватный `DETECTOR_SERVICE_TOKEN` не короче 32 символов. Inference не скачивает модели автоматически и не должен иметь публичный порт или исходящий Интернет.

## Честно о качестве

18 тестовых текстов — небольшой, нерепрезентативный исследовательский корпус: 12 литературных фрагментов и 6 машинных примеров. Отсутствие пересечения с недоступным исходным обучающим корпусом доказать нельзя. FPR=0 на 12 примерах **не означает FPR ≤ 3%**.

Полноценная собственная модель студии **пока не обучена**. Реальный шаг градиента проверяет инфраструктуру, но не создаёт валидированный детектор. Для полного обучения нужен разрешённый разнообразный корпус.

Агрегация логитов длинного текста — наша экспериментальная адаптация, независимо не откалиброванная. Цвет абзаца переносится с контекстного окна и не устанавливает происхождение отдельного предложения. Короткие фрагменты отмечаются нейтрально.
