## Безопасность

Публичный запрос не принимает путь, URL или код модели. ID проверяется allowlist, пути и SHA-256 — перед загрузкой. Transformer inference читает safetensors/JSON, с `local_files_only=True`, `trust_remote_code=False`.

Преобразование старых calibrator pickle допускает только просмотренные immutable-артефакты с закреплённым SHA-256. Опциональная v1 также допускает только известный classifier hash. Пользовательский pickle загрузить нельзя.

Файл до 5 МБ, DOCX после распаковки до 20 МБ/1000 элементов, PDF до 40 страниц, текст до 60 тысяч символов. Извлечение идёт отдельно, с RLIMIT/тайм-аутом и максимум двумя процессами. OCR и обход шифрованных PDF отсутствуют.

Access logs отключены, inference-сеть internal, rootfs и модели read-only, non-root, cap_drop и RAM/CPU/PID limits. При тайм-ауте убивается пул; при maxParallel=2 это может прервать соседний запрос. Его квота возвращается сервером студии. Перед production нужна изолированная очередь с отменой по задаче.

Проверка целостности кешируется по хешу, размеру и mtime каждого артефакта. Манифест — доверенная конфигурация оператора, а не вход пользователя. Исправлен путь `evaluation/evaluate_v4.py` исходного shell pipeline.

## Исследование и ресурсы

Docker: 16 CPU, около 16 ГиБ RAM. RTX 5060 Ti 16 ГиБ обнаружена на хосте, CUDA-обучение не проверено. Реально проверен CPU.

Микробенчмарк одного короткого текста на первоначальном стеке Torch 2.8 / Transformers 4.57.6, отдельные процессы:

| Путь | Cold | Медиана 3 warm | RSS |
|---|---:|---:|---:|
| Исходный v2 с дополнительным GPT-расчётом | 10432 мс | 362 мс | 988 МБ |
| Быстрый KA v2 без ненужного GPT | 1699 мс | 13 мс | 406 МБ |

Не гарантия скорости. Новым библиотекам эти старые числа не приписываются. `peakMemoryMb` результата — максимальный RSS процесса за его жизнь, не инкремент конкретной модели.

На 18 примерах recall v1/v2/v3/v4: 0 / 1 / 0,5 / 0,5; FPR=0 на 12 литературных фрагментах. Верхняя граница Wilson 95% для FPR около 24,25%, не 3%. Нет покрытия всех жанров, редактур и новых генераторов; независимость от исходного обучения не доказана. Порог v1 не подгонялся по test ради метрики.

CPU gradient smoke: seed 27, один optimizer step, loss 1,16336, около 2,65 с на шаг/сохранение на первоначальном стеке. Это не обученная рабочая модель студии.

## Зависимости

Первый pip-audit выявил 29 advisory в Transformers 4.57.6, filelock 3.32.3, pip 25.0.1 и setuptools 78.1.0. Новая сборка обновляет их до исправленных версий; повторный результат сверяется с точным image/lock. Отсутствие известных advisory не доказывает отсутствие уязвимостей.

Официальные версии: [Transformers](https://pypi.org/project/transformers/), [filelock](https://pypi.org/project/filelock/), [setuptools](https://pypi.org/project/setuptools/), [pip](https://pypi.org/project/pip/).

CPU wheel `torch==2.8.0+cpu` был пропущен pip-audit как отсутствующий на PyPI. Отдельная проверка PyPI JSON для базовой версии 2.8.0 выявила ещё 8 advisory. Поэтому финальный runtime использует **Torch 2.14.1+cpu, Transformers 5.21.0, huggingface-hub 2.3.0, filelock 4.2.4, pip 26.2.2, setuptools 84.2.1**. Для [базовой версии Torch 2.14.1](https://pypi.org/pypi/torch/2.14.1/json) список vulnerabilities пуст; CPU wheel получен из официального индекса PyTorch. Пропуск CPU wheel в pip-audit не скрывается и не считается самостоятельной проверкой его бинарного содержимого.

Финальная сборка прошла `pip check`, 15 Python-проверок с реальными моделями, повторное сравнение v1–v4 на том же корпусе, градиентный smoke и реальные браузерные сценарии студии. В новом smoke loss 1,16336274, 4537 мс, seed 27, CPU. Docker/OS CVE-скан и независимый пентест этим аудитом не заменяются.

Полный корпус и веса не публикуются в новых коммитах. В `seed_corpus.py` есть только явно помеченные синтетические тестовые примеры; они не выдаются за человеческие и не являются обучающим корпусом.
